# **App Name**: Talent Track

## Core Features:

- Candidate Search: Allows searching of candidates by name, skills or other criteria
- Candidate Filtering: Allows filtering of candidates by status, courses, CADD score etc.
- Candidate Display: Presents a list of candidates, each with a summary of information and a photo
- Candidate Details: Shows complete details of a selected candidate including skills, contact information and topics.
- Intelligent Matching: Use AI tool to match candidate skillset with listed topics

## Style Guidelines:

- Primary color: Light orange (#FFB347) to give a bright, inviting feel.
- Background color: White (#FAFAFA) to offer a clean and modern interface.
- Accent color: Pale yellow (#FAF9D9), subtly lighter than the orange.
- Body and headline font: 'Inter' for a modern, neutral and readable appearance.
- Simple, professional icons for navigation and key actions.
- Clean, card-based layout for presenting candidates and their information.
- Subtle transitions when displaying candidate details.
